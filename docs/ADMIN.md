# Как править сайт

Все тексты сайта правятся прямо на страницах, а книги добавляются кнопкой.
Изменения сохраняются в репозиторий GitHub, и сайт обновляется **через 1–2 минуты**.

## Включить редактирование (один раз в браузере)

Откройте любую страницу сайта с `?edit` в конце адреса, например
**https://oxana-s.github.io/Roni-Site/?edit**

Внизу справа появится кнопка **«✎ Редактировать»**. Браузер её запомнит, обычные посетители её не видят.
Чтобы убрать кнопку из браузера, откройте адрес с `?edit=0`.

## Как править

1. Нажмите **«✎ Редактировать»**. Все тексты, которые можно менять, обведутся пунктиром.
2. Кликните по тексту и исправьте его. **Enter** или клик мимо — готово, **Esc** — отмена.
   - В абзацах главы и описаниях Enter начинает новый абзац.
   - Чтобы перейти по ссылке в режиме правки, нажмите **Ctrl+клик**.
3. **Обложка книги**: кликните по картинке и выберите файл (JPG/PNG, до 5 МБ).
4. Нажмите **«Сохранить»**. Правки всей страницы уйдут одним сохранением.
   Перед переходом на другую страницу сохраните правки, иначе браузер предупредит.

## Конструктор: элементы, секции, картинки, аудио

**Всё работает по клику.** Кликните по элементу — над ним появится его панель, а справа вверху секции — панель секции. Клик мимо или **Esc** — снять выделение.
При наведении элемент только слегка обводится. Пустые места и обёртки не выделяются, только сами элементы:
заголовки, тексты, картинки, кнопки, ссылки, плееры, карточки.

**Двигать можно только элементы, секции стоят на своих местах.**
- **Родной элемент** (заголовок, текст, фото, кнопка, плеер): на его панели **⠿ Двигать** — тяните куда нужно.
  Шаг 4 px, у центра секции элемент прилипает (розовая линия). Shift — без привязки.
  **Размер:** у выделенного элемента голубые ручки справа (ширина) и снизу (высота) — так, например, продлевается полоска таймлайна в новостях.
  Тонкие линии выбираются кликом рядом с ними.
  **⧉ Копия** — копия элемента (карточка, полоска, кнопка…) встаёт рядом как новый элемент: её можно тянуть за ⠿, менять ширину и высоту,
  править текст прямо в ней.
  **↺** — вернуть на место и в прежний размер, **Скрыть** — спрятать от посетителей (у вас он бледный; вернуть — «👁 Показать»).
  **🗑 Удалить** — убрать элемент со страницы совсем (и у вас тоже). Если удалили лишнее — кликните по секции,
  на её панели **«↩ Вернуть удалённые (N)»**.
  На телефоне сдвиги родных элементов не применяются, чтобы ничего не уехало за край экрана. Скрытие работает везде.
- **Новый элемент:** на панели секции **«+ Элемент»** → заголовок, текст, 🔗 кнопка, 🖼 картинка, 🎙 аудио, цитата, 📖 книга.
  Его панель: **⠿** — перетащить (рядом с другими элементами он прилипает), ⇤ ↔ ⇥ — выравнивание, 🖼/🎙 — заменить файл, 🔗 — куда ведёт кнопка,
  📖 — другая книга, **⧉ — дублировать рядом** (так удобно поставить две кнопки рядом), ✕ — удалить. Ширина — золотая ручка справа.
  Если элемент стоит ниже края секции, секция сама становится выше. На телефоне элементы встают колонкой, элементы на одной высоте — рядом, если помещаются.

**Новая страница из кнопки.** У кнопки нажмите 🔗 и впишите имя страницы, которой ещё нет: например `events` или «О нас»
(кириллица превратится в латиницу: `o-nas.html`). При «Сохранить» страница создастся сама: шапка, подвал и секция с заголовком «Новая страница».
Перейдите на неё и наполняйте как любую другую: заголовок правится кликом, «+ Элемент» — в панели секции.
Существующие страницы так не перезаписываются: ссылка на `books` просто поведёт на `books.html`. В меню сайта новая страница сама не добавляется.

**Подвал** — общий для всех страниц: кликните по нему, на его панели «+ Элемент». Добавленное и сдвинутое в подвале видно на всём сайте.

**Панель секции:** «+ Элемент», **«Скрыть»** (у вас секция бледная, у посетителей её нет), **«+ Секция ниже»** — новая пустая секция с заголовком.
У своей секции ещё есть 🎨 смена фона (тёмный / темнее / с сиянием), **🖼 Фон** — картинка на фон, ✕ — удалить.

**Карточка книги** (на главной, в «Других книгах»): кликните — ↑ ↓ (порядок книг), **⚙ Настройки** (цена, статус, Amazon, описание) и ✕.

**Любая картинка сайта** — фото, фон героя, картинки «двух миров», обложки: кликните по ней (можно прямо по подписи или затемнению поверх картинки),
на панели элемента нажмите **«🖼 Заменить картинку»** и выберите файл (до 8 МБ). Картинка заменится **на этой странице**
(в подвале — на всех страницах); обложка книги — в данных книги. Большой фон на всю секцию можно только заменить, не двигать.
**Обложка новой книги**: пока её нет, на карточке пустая обложка; кликните по ней → «🖼 Заменить картинку».

**Аудио.** Все записи на сайте играют в одном плеере, как в «Голосе автора»: золотая кнопка, волна, время.
Под плеером есть кнопка **«🎙 Заменить запись»**. На странице книги и на странице её главы кнопка **«🎙 Аудио главы»** на панели добавляет книге запись:
на странице книги появляется секция «Голос автора», на странице главы — «Слушать главу». Записи — mp3/m4a, до 60 МБ.

Тексты элементов правятся на текущем языке. Если перевода нет, показывается русский.

**Другой язык.** Переключите язык в шапке сайта (EN / UK / RU / BG) и правьте так же.
Панель всегда показывает, какой язык сейчас правится.

**Кнопка «Книги».** Здесь то, чего не видно в тексте: статус («Опубликована» или «Скоро»), цена, ссылка на Amazon, оформление, порядок книг, большой блок на главной, полное описание, удаление книги и **«Добавить книгу»**.

**Кнопка «Текст главы»** (на странице первой главы) открывает главу целиком. Новую главу удобно вставлять сюда из Word:
абзацы разделяйте пустой строкой, реплики начинайте с «— ».

### Новая книга по шагам
1. **Книги → Добавить книгу**: введите код латиницей (например `ghost-2`) и название.
   В редакторе книга сохраняется сразу после «Добавить».
   Её страница — **`book.html?id=код`** — сразу выглядит как «Просто вернуться домой» со всеми секциями
   (герой, «Что внутри», «Два мира», отрывок, отзывы, автор, покупка) и с вашими правками той страницы.
   Название, подзаголовок, обложка, цена и Amazon — новой книги; «Читать главу» и «Купить» ведут на её главу и заказ.
   Меняйте прямо на странице: тексты, картинки, элементы. Правки касаются только этой книги; всё, что не трогали,
   берётся от «Просто вернуться домой» (поменяли там — поменяется и тут).
   Глава — **`read.html?book=код`**: пока своей главы нет, показывается глава «Просто вернуться домой» как заготовка.
   Первая правка (в тексте или через **«Текст главы»**) создаёт главу этой книги — замените текст и сохраните.
2. В том же окне загрузите обложку и заполните цену и описание, снова **Сохранить**.
3. Ссылка **«Первая глава»** → кнопка **«Текст главы»** → вставьте текст → **Готово** → **Сохранить**.
4. Когда книга готова к продаже, поставьте статус **«Опубликована»**.

## Вход для сохранения (один раз)

При первом сохранении сайт попросит **токен GitHub**. Аккаунт должен иметь право записи в репозиторий `Oxana-S/Roni-Site`.

- **Владелец репозитория (Oxana-S)** создаёт fine-grained токен:
  https://github.com/settings/personal-access-tokens/new → Repository access: Only select → `Roni-Site` →
  Permissions → Contents: **Read and write** → Generate token.
- **Соавтор** (его добавили в Settings → Collaborators): classic-токен на
  https://github.com/settings/tokens/new с галочкой **public_repo**.

Токен хранится только в этом браузере. Никому его не пересылайте.

## Проверка на своём компьютере (без GitHub и токена)

```
python scripts/edit-server.py
```
Откройте **http://localhost:8765/?edit**. «Сохранить» пишет прямо в файлы проекта (`data/…`, `assets/img/books/…`).
Дальше эти файлы коммитятся обычным git.

Можно работать и через **Live Server** в VS Code (`http://127.0.0.1:5500/Roni-Site/?edit`): пока `edit-server.py` запущен,
редактор отправляет «Сохранить» на него, а Live Server сам обновит страницу. Если сервер не запущен — редактор об этом напишет.

Режим правки включается только в той вкладке, где открыли `?edit`. В других вкладках и при обычном заходе сайт выглядит как у посетителя.
Убрать кнопку из вкладки — ✕ рядом с «✎ Редактировать».

## Что не правится на сайте

- Тексты внутри кнопок с ценой («Купить · 3.99 €»). Цену меняйте в **Книги**, слово «Купить» — в коде.
- SEO-заголовки вкладки браузера (`assets/seo-meta.js`).

## Как это устроено (для разработчика)

- Тексты по умолчанию остаются в коде: `DICT`/`CH` в каждой странице и компоненте.
  Правки с сайта хранятся в `data/texts.json` в виде `{ "index.html": { "DICT.ru.heroTitle": "…" } }`
  и подставляются поверх. Чтобы вернуть текст из кода, удалите строку в `data/texts.json`.
- `assets/texts.js` подставляет правки и включает режим `?edit`. Каждый компонент регистрируется в конструкторе:
  `constructor(p){ super(p); window.RoniTexts&&RoniTexts.register(this,'имя.html',['DICT']); }`.
  **Новая страница** должна подключать `assets/texts.js` и регистрироваться так же, иначе её тексты не будут редактироваться.
- `assets/editor.js` — сам редактор. Он загружается только у тех, кто включил `?edit`.
  Текст на экране сопоставляется с ключом словаря по значению внутри компонента, где кликнули (`data-sc-name`).
  Сохраняет одним коммитом через GitHub API. Перед записью перечитывает свежие файлы, поэтому чужие правки не затираются.
- Книги: `data/books.json`, главы: `data/chapters/<код>.json`, загрузка — `assets/books.js`.
  Страницы: `books.html?id=`, `read.html?book=`, `order.html?book=`.
- Конструктор: `assets/layout.js` у всех посетителей добавляет в секции слой свободных элементов (`free`), свои секции (`custom`), порядок (`order`), скрытие (`hidden`) и подменяет картинки и аудио (`media`) по `data/layout.json`.
  Слой элементов — по центру секции шириной как контейнер сайта; координаты: `x` и `w` в % ширины слоя, `y` в px от верха секции. На ширине ≤ 700px слой становится обычной колонкой.
  Ключ секции: `id` → `data-screen-label` → `тег-номер`; своя секция — `c-<id>`. Если переставить секции в коде, элементы секций без `id` (привязка по номеру) могут переехать в соседнюю секцию.
  Порядок секций (`order`) теперь меняется только появлением своих секций («+ Секция ниже»); через CSS `order`, DOM-узлы React не переставляются.
  Сдвиги и размеры родных элементов — `moves`: `{ "<секция>": { "<путь>": { "dx", "dy", "w", "h", "hide", "del" } } }` (`translate`, `width`/`height` в px; родные инлайн-размеры запоминаются и возвращаются по «↺»).
  Подвал — общий: его `free` и `moves` лежат в `global` (ключ секции `footer`). Копия элемента — свободный элемент `type: "clone"` с очищенным `html`.
  Путь — индексы детей от секции («0.1.2»), вставки конструктора не считаются. Если поменять вёрстку секции в коде, сдвиги в ней могут попасть на другие элементы — тогда сбросьте их (↺) или удалите `moves` этой секции.
  Плеер сайта: `<audio data-rl-enhance data-rl-title="…" src="…">` в вёрстке превращается в плеер «как в Голосе автора».
  Загруженные файлы лежат в `assets/uploads/`.
- Страница книги — `book.html?id=код`, глава — `read.html?book=код` (без файлов-копий). Ключ правок такой страницы —
  `book.html?id=код` / `read.html?book=код` в `data/texts.json` и `data/layout.json`; тексты сначала берутся от `book.html` / `read.html`,
  поверх — свои. Макет конструктора наследуется до первой правки, при первой правке копируется в свою версию целиком.
  Нет своей главы — `read.html` показывает копию `home.json`; первая правка сохраняет `data/chapters/<код>.json` целиком.
  Старые копии `book-ghost2.html` / `read-ghost2.html` (поля `page` / `read_page`) продолжают работать.
- Замена картинок: `pages[…].media` — для страницы, общий `media` — для подвала (и замены, сделанные до этого изменения).
- Новые страницы создаются из шаблона `assets/new-page.template.html` (имя файла — ключ правок страницы в `data/texts.json` и `data/layout.json`).
  Локальный сервер пишет новый `имя.html` в корень, только если такого файла нет; на GitHub редактор тоже проверяет это перед записью.
