# Магазин: оплата книг через myPOS

Покупатель на `order.html` вводит e-mail и имя → переходит на защищённую страницу оплаты myPOS →
после оплаты возвращается на сайт и сразу скачивает книгу; ссылки на скачивание приходят и на почту.
Автору приходит письмо о каждой продаже.

## Как устроено

| Файл | Что делает |
|---|---|
| `order.html` | Форма заказа и экраны результата («Подтверждаем оплату», «Спасибо» с кнопками скачивания, «Оплата не завершена») |
| `shop/checkout.php` | Создаёт заказ, берёт цену из каталога (`data/books.json`), подписывает запрос и отправляет покупателя в myPOS |
| `shop/notify.php` | Сюда myPOS сообщает об оплате (сервер → сервер). Проверяет подпись myPOS, магазин, сумму, валюту → заказ оплачен → письма |
| `shop/return.php` | Возврат покупателя с myPOS на сайт (ничего не подтверждает) |
| `shop/status.php` | Статус заказа для экрана «Спасибо» |
| `shop/download.php` | Скачивание по личной ссылке: 30 дней, до 10 раз (настраивается) |
| `shop/config.php` | Настройки и ключ myPOS. **Только на хостинге**, в git не попадает |
| `shop/.data/orders/` | Заказы (создаётся сам, закрыт от браузера) |

**Цена** — поле «Цена» книги в админке («Книги»), на языке покупателя. Магазин myPOS принимает только **EUR**:
если на каком-то языке цена указана не в евро (например, `$2.99` у английской версии), берётся русская цена в евро.
Лучше указать на всех языках цену в евро, например `3.99 €`.

**Продаётся** книга со статусом «Опубликована» и с ценой в евро. У остальных вместо кнопки — «пока не продаётся».
Статус и наличие книги проверяются для языка заказа. Если в «Книги» у книги снята галочка этого языка, страница заказа
на этом языке пишет, что книги на нём нет; если для этого языка стоит «Скоро» — что книга пока не продаётся.
`shop/checkout.php` такой заказ тоже не примет.

## Установка на хостинг

### 1. Файлы книг — вне папки сайта
Через FileZilla или файловый менеджер ISPmanager откройте папку **на уровень выше** папки сайта
(там, где лежит папка `vishnevsky.info`), создайте папку **`book-files`** и положите файлы
с именем **код книги + язык в конце**:

```
book-files/ghost-ru.pdf     ← заказ оформлен на русской версии сайта
book-files/ghost-ru.epub
book-files/ghost_EN.pdf     ← на английской
book-files/ghost_UA.pdf     ← на украинской (UA или UK)
book-files/ghost-bg.pdf     ← на болгарской
```
Регистр букв и разделитель (`-`, `_`, пробел) не важны; на каждый язык и формат — один файл.
Вместо кода в начале имени можно своё слово — `'file_names'` в `shop/lib.php` / `shop/config.php`
(сейчас `ghost` → `Detective`: подходят и `Detective_EN.pdf`, и `ghost-en.pdf`).
Покупатель получает файл **на том языке, на котором оформлял заказ**. Если файла на этом языке нет,
выдаётся общий `ghost.pdf` (без языка), если он есть; если нет и его — автору приходит письмо «отправьте вручную».
Поэтому общий файл без языка оставляйте, только если книга одна для всех языков.

Код книги — в админке «Книги» (или в адресе `order.html?book=ghost`). Языки: ru, en, uk, bg.
Форматы: pdf, epub, mobi, fb2, azw3, zip.

**Не кладите книги внутрь папки сайта**: картинки и PDF хостинг отдаёт напрямую, мимо всех защит, — их можно было бы скачать без оплаты.
Если книгу положить некуда — в `shop/config.php` есть `files_dir` (полный путь к папке).

Если файла нет, покупатель видит «Оплата получена, автор пришлёт книгу», а автору приходит письмо «ФАЙЛА НЕТ — отправьте вручную».

**Проверка без покупки**: войдите в `/admin/` и откройте `https://vishnevsky.info/shop/files.php` — там для каждой книги
и языка видно, какой файл получит покупатель, а внизу — файлы, имя которых не подошло ни к одной книге.

### 2. Настройки
Скопируйте `shop/config.sample.php` → `shop/config.php`, проверьте `notify` (почта для уведомлений о продажах),
загрузите в папку `shop/` на хостинге. Начните с `'mode' => 'test'`.

### 3. Тестовая покупка
Тестовый режим работает только для того, кто вошёл в `/admin/` (иначе любой посетитель «купил» бы книгу бесплатно).
1. Войдите в `https://vishnevsky.info/admin/`.
2. В этой же вкладке откройте книгу → «Купить» → заполните форму → «Перейти к оплате».
3. На тестовой странице myPOS введите любые данные карты — тестовая оплата всегда проходит, деньги не списываются.
4. Должно быть: возврат на сайт → «Спасибо за покупку!» с пометкой «ТЕСТОВЫЙ ЗАКАЗ» → кнопки скачивания работают →
   письмо покупателю со ссылками и письмо автору «[ТЕСТ] Продажа…».

### 4. Боевой режим
1. Откройте файл с configuration pack из myPOS (`$cnf->loadConfigurationPackage('…');`).
2. В `shop/config.php` вставьте в `'pack' => ''` **только то, что внутри кавычек** (длинная строка `eyJ…`).
3. Поменяйте `'mode' => 'live'` и загрузите `shop/config.php` на хостинг.
4. Сделайте одну настоящую покупку и проверьте письмо и деньги в кабинете myPOS (Stores → магазин → Transactions).

Ключ лежит только в `shop/config.php` на хостинге и у вас. Никому его не пересылайте; если он мог утечь —
в myPOS (Integration) создайте новую конфигурацию, старую удалите, обновите `pack`.

### 5. Выключить оплату
`'mode' => 'off'` — кнопка остаётся, но вместо перехода к оплате покупатель увидит «временно недоступна».

## Если что-то не так
- **Письма не приходят** (ни покупателю, ни автору): хостинг не отправляет почту с адреса `books@vishnevsky.info`.
  Создайте этот ящик в ISPmanager («Почта») или укажите в `'from'` существующий ящик на домене. Книгу покупатель
  всё равно скачает на экране «Спасибо».
- **Письма в спаме**: в ISPmanager для домена включите SPF и DKIM.
- **Почта через Brevo** (`smtp-relay.brevo.com:587`, логин и SMTP-ключ из Brevo → SMTP & API, `'from' => 'books@vishnevsky.info'`):
  ключ Brevo отключается после 90 дней без писем. Чтобы этого не случилось, в ISPmanager → «Планировщик CRON» стоит задание
  раз в месяц (1-го числа) `wget -q -O /dev/null https://vishnevsky.info/shop/keepalive.php` — оно отправляет на `notify` служебное письмо
  не чаще раза в 25 дней.
- **«Подтверждаем оплату…» висит**: myPOS не достучался до `shop/notify.php`. Проверьте, что сайт работает по https,
  и посмотрите заказ в `shop/.data/orders/` (файл с номером заказа: статус `new` = уведомления не было).
- **Ссылка истекла** — покупатель отвечает на письмо; автор пересылает файл вручную.

## Юридически (до боевого запуска)
На сайте нужны страницы «Условия продажи», «Политика конфиденциальности» и «Возврат» с реквизитами ROSTVISH EOOD,
и e-mail для связи. Галочка «отказ от права на возврат после начала скачивания» на странице заказа уже есть.
Тексты стоит показать бухгалтеру; ему же — вопрос НДС при продажах в другие страны ЕС (OSS).
