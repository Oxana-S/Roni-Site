# SEO сайта

Как сайт показывается в Google, Bing и Яндексе и в превью ссылок в соцсетях, и что сделать после подключения домена.

## Как это устроено

Сайт рисуется в браузере (JavaScript), язык выбирается кнопками в шапке. Чтобы поисковики видели все четыре языка
и правильные заголовки, есть три части:

| Часть | Файл | Что делает |
|---|---|---|
| Тексты и настройки | `assets/seo.json` | Заголовки, описания, ключевые слова страниц на 4 языках, имя автора, соцсети, коды подтверждения поисковиков |
| Сервер | `.htaccess` + `seo/page.php` | Каждой странице дописывает на нужном языке: title, description, canonical, hreflang, Open Graph, разметку schema.org и текстовую версию страницы для тех, кто не выполняет JavaScript |
| Сервер | `seo/sitemap.php`, `seo/robots.php` | `/sitemap.xml` и `/robots.txt` собираются сами — с вашим доменом и книгами из админки |
| Браузер | `assets/seo-meta.js` | `?lang=en` в адресе открывает английскую версию; при смене языка меняется адрес и заголовок вкладки |

**Адреса языков.** У каждой страницы четыре адреса: `about.html` (русский), `about.html?lang=en`, `?lang=uk`, `?lang=bg`.
Они связаны тегами `hreflang` — поисковик показывает человеку версию на его языке.
У первой главы языки только те, на которых есть свой текст главы (у «Призрачного детектива» сейчас RU и EN).

**Книги из админки.** Новая книга со статусом «Опубликована» сама попадает в sitemap, получает свой заголовок,
описание (из «Короткого описания»), картинку для соцсетей (обложку) и разметку Book. Книга «Скоро» скрыта от поисковиков
(её страница пока собрана из макета). Первая глава попадает в поиск, когда у неё есть свой текст.

**Без сервера** (локально, или если хостинг не выполняет `.htaccess`) сайт работает как раньше: в страницах лежат
русские мета-теги, `sitemap.xml` и `robots.txt` — статичные запасные файлы.

## Что загрузить на хостинг

Новое и изменённое (можно заменять смело, данных админки тут нет):
- `.htaccess` (в корне сайта; скрытый файл — в FileZilla включите показ скрытых файлов);
- папка `seo/` целиком (с её `.htaccess`);
- `assets/seo.json`, `assets/seo-meta.js`, `assets/editor.js`, `assets/new-page.template.html`;
- папка `assets/og/` (картинки для превью в соцсетях) и `assets/vendor/.htaccess`;
- `index.html`, `about.html`, `article.html`, `book.html`, `books.html`, `order.html`, `return-home.html`;
- `sitemap.xml`, `robots.txt` (запасные).

`data/`, `assets/uploads/`, `assets/img/books/` и `admin/config.php` **не трогайте** — см. docs/ADMIN.md.

## Как проверить, что серверная часть работает

1. Откройте любую страницу сайта → правый клик → «Просмотр кода страницы» (Ctrl+U).
   В начале должно быть `<!-- seo -->` и строки `<link rel="alternate" hreflang="en" …>`.
2. Откройте `https://ваш-домен/sitemap.xml` — в нём должны быть адреса с `?lang=en` и ваш домен (не github.io).
3. Откройте `https://ваш-домен/about.html?lang=en` — заголовок вкладки по-английски сразу, ещё до загрузки сайта.

Если в коде страницы нет `<!-- seo -->`:
- хостинг не выполняет `.htaccess` (так бывает, если сайт работает только на nginx). В ISPmanager:
  «Сайты» → ваш сайт → обработчик **Apache** / «PHP как модуль Apache» или «CGI/FPM через Apache».
  Если не получается — напишите в поддержку RichHost: «нужно, чтобы работал .htaccess с mod_rewrite».
- Если сайт отвечает «500 Internal Server Error» — удалите `.htaccess` из корня сайта (сайт заработает как раньше)
  и напишите в поддержку, какой модуль не включён.

## После подключения домена — по порядку

1. **SSL.** В ISPmanager выпустите бесплатный сертификат Let's Encrypt для домена и включите
   «Перенаправлять HTTP-запросы в HTTPS». Если такой галочки нет — в `.htaccess` уберите `#` у трёх строк блока
   «HTTPS и единый адрес». Решите, с `www` или без: блок там же.
2. **Домен в файлах.** На своём компьютере:
   ```
   python scripts/set-domain.py https://ваш-домен
   ```
   и загрузите на хостинг: `*.html`, `sitemap.xml`, `robots.txt`, `assets/seo.json`.
   (Сервер и сам подставляет домен, но так адрес будет одним и тем же для всех: https и с/без www.)
3. **Google Search Console** (search.google.com/search-console): добавьте ресурс «Домен» или «Префикс URL».
   Подтверждение через HTML-тег: скопируйте из тега только значение `content="…"` и впишите в `assets/seo.json` →
   `"verification": { "google": "…" }`, загрузите файл. Затем «Файлы Sitemap» → `sitemap.xml`.
4. **Bing Webmaster Tools** (bing.com/webmasters): «Импорт из Google Search Console» — одной кнопкой.
   На индексе Bing работает и выдача Yahoo и DuckDuckGo.
5. **Яндекс Вебмастер** (webmaster.yandex.ru) — если нужны читатели из Яндекса: код подтверждения → `"yandex"`,
   добавьте sitemap.
6. **Старая копия на GitHub Pages** (`oxana-s.github.io/Roni-Site/`) — выключите её
   (GitHub → репозиторий → Settings → Pages → «None»), иначе в поиске будет два одинаковых сайта.
7. **Проверка превью и разметки:**
   - Google Rich Results Test (search.google.com/test/rich-results) — главная, страница книги, глава, статья;
   - Facebook Sharing Debugger (developers.facebook.com/tools/debug) — превью ссылок, кнопка «Scrape Again» после правок.

## Как менять тексты для поисковиков

`assets/seo.json`, раздел `pages` → страница → язык:
- `t` — заголовок (до ~60 символов, видно в выдаче и на вкладке);
- `d` — описание (до ~160 символов, текст под заголовком в выдаче);
- `k` — ключевые слова (поисковики почти не используют, можно не трогать).

Другие поля: `author` (имя на 4 языках, псевдонимы, город, ссылки на соцсети — добавляйте сюда YouTube/Instagram/Amazon,
когда появятся), `ogImage` (картинка превью по умолчанию), `patterns` (шаблоны заголовков книг, глав, статей),
`books` (жанр книги для разметки), `articles` (заголовки и анонсы статей блога).

Заголовки страниц книг и глав берутся из админки (название и «Короткое описание» книги) — отдельно их писать не нужно.

**Цена в выдаче Google.** Сейчас выключена (`"offers": false`): оплата на сайте ещё не подключена (кнопка «Купить»
только показывает экран «спасибо»), а Google не любит цены на то, что нельзя купить. Когда заработает оплата —
поставьте `"offers": true`: у книг в разметке появится цена из админки.

## Что ещё повлияет на позиции (зависит от контента)

- **Картинки блога** (`assets/img/blog-1…6.jpg`), `book-2.jpg`, `world-earth.jpg`, `world-tolus.jpg` — пока заглушки
  с подписью имени файла. Они же уходят в превью статей в соцсетях. Замените реальными (размеры — docs/IMAGES-spec.md).
- **Отзывы** (`reviews.html`) — примеры. Разметку рейтинга для Google на них не делали намеренно: за выдуманные отзывы
  сайт можно потерять в поиске. Когда будут настоящие отзывы — можно добавить.
- **Первая глава «Призрачного детектива» на украинском и болгарском** — сейчас там русский текст, поэтому эти версии
  не отдаются поисковикам. Появится перевод — появятся и в поиске.
- **Ссылка на Amazon** — после замены `REPLACE_WITH_ASIN` на настоящую (в админке, «Книги») она попадёт в разметку книги.
- Ссылки на сайт с других сайтов (Facebook, Goodreads, LiveLib, интервью, каталоги книг) — главное, что поднимает
  новый сайт в выдаче.
